# Australian Caselaw Digest

A daily plain-language digest of recent decisions by Australian courts and
tribunals, generated automatically from public data published by
[AustLII](https://www.austlii.edu.au).

**Live site:** <https://changa9090.github.io/au-caselaw-digest/>

- Summaries are auto-generated and may be incomplete or out of date.
- Only the full text on AustLII (linked from every card) is authoritative.
- Nothing on the site is legal advice.

`index.html` is rebuilt every morning by an automated pipeline and served via
GitHub Pages.
